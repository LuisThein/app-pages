# app-pages

Static GitHub Pages site for public app pages such as privacy policy, support, and imprint.

## Structure

- `index.html`: landing page for all app pages
- `never-havi-i-ever/`: public pages for the Never Have I Ever app

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open repository settings.
3. Enable GitHub Pages from the main branch and root folder.
4. Use the generated public URLs in App Store Connect.

## Replace before publishing

- Contact email address
- Legal name / company name
- Postal address in the imprint
- Optional support links
